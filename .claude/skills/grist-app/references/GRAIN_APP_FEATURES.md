# Grain web app: features and screens

Observed 2025-09-05 at `grain.com/app` as a non-admin member of a
Business-plan workspace without a paid recording seat. This file describes
the product only. API mapping lives in `PARITY.md`.

## Information architecture

```
Sidebar
├── Workspace switcher      → Account settings · Workspace settings · Open in desktop app · Sign out
├── + New                   → Desktop Capture · Bot recording · File upload · Zoom import
├── Search
├── Updates (unread badge)  → notifications popover
├── Meetings                → primary list
├── Playlists
├── Stories                 → Stories tab · Clips tab
├── Coaching                → paid seat required
└── Invite · Help
Floating "Ask anything…" (⇧A) → AI chat over all meetings (Beta)
```

## Meetings list (`/app/meetings`)

The landing page.

**View tabs:** My meetings · Workspace meetings · one tab per team (URL
`/app/meetings/teams/<uuid>`).

**Up next:** upcoming calendar events with date badge, title, recurring
icon, time, Internal/External label, company chip, recorder count,
participant count, and a per-event auto-capture selector (Auto-capture with
Grain Bot · Auto-capture with Grain Desktop · Don't auto-capture). "Show all"
expands.

**History:** grouped by day ("Today", "Yesterday", "Wednesday, Aug 26th"),
newest first, infinite scroll. Row = thumbnail · title (+ recurring icon) ·
start time · duration · Internal/External · company chip · recorder avatar
and count · participant count.

**Controls:**
- Filter by title (text box).
- Filters: Date, Participants, Team, Company, Recorder, Trackers, Tags,
  Meeting Type.
- List properties (column toggles): Team, Company, Recorder, Participants,
  Sensitivity, Meeting tags, Trackers, Comments, Clips, Views, Meeting type,
  Playlists.
- ⋮ → Recently deleted (restore).

## Meeting detail (`/share/recording/<uuid>/<token>`)

Two-pane on desktop: left notes/transcript, right player and timeline.

**Header:** breadcrumb · title (inline-editable by owner) · chips: date,
participants ("aashish +3" → popover), teams ("1 team"), sensitivity
("Pending", tooltip explains rules run after recording), ⋮ (Meeting type ·
Viewers · Automation sharing).

**Top-right actions:**
- Share dialog: add people by name/email, per-person Can edit/Can view,
  team entries ("People in Sales · 19 people"), Workspace access, Link
  access, "Start at 00:00", Copy link.
- Copy link.
- ✱ AI menu: Open in Claude · Open in ChatGPT · Copy transcript for AI ·
  Download transcript for AI · Connect to Claude/ChatGPT via Grain MCP.
- ⋮ menu: Copy ▸ · Download ▸ · Send to Slack · Send to Salesforce · Send
  follow-up email · Add to playlist ▸ · Add all clips to story ▸ · Add tags ▸
  · Edit transcript · Change transcript language ▸ · Delete recording.

**Left pane tabs:**

- *Summary.* Search-summary box, copy, send menu (HubSpot · Slack ·
  Salesforce · follow-up email). **Action Items** grouped by assignee
  (avatar · name · company), each with checkbox and a timestamp that seeks
  the player. **Summary** bullets with bold names and seek timestamps.
  **Template sections** (titled bullet groups such as "Proposed Timeline &
  Next Steps", "Open Questions") generated by the AI template attached to
  the meeting type. Bottom: "Add custom template" → Customize Summary modal
  listing Grain templates (Sales Discovery, Sales Follow-Up, Customer
  Feedback, Partner Check-in, …) and Template settings.
- *Private Notes.* Per-user rich-text editor ("Write or type / for
  commands…"). Not visible to others.
- *Transcript.* Search box, comment counter, copy, ⋮ (Edit Transcript ·
  Change transcript language ▸ · Download transcript ▸). Body grouped by
  **Chapter** headings, then speaker blocks (avatar · name · text). Tap a
  line to seek; current line highlights during playback. Hover reveals
  create-clip / comment / copy.

**Right pane:**

- *Player.* Current time · chapter title · total time; scrubber with chapter
  markers; volume; speed (1, 1.2, 1.5, 1.7, 2, 2.2, 2.5); −10s · play · +10s;
  picture-in-picture; fullscreen.
- *Timeline tab.* Per-speaker bars: name · talk percentage · minutes, with
  shading where each spoke. External participants also aggregate by company
  ("Pylon 20% · 8m"). **Screenshare** row with shaded ranges and total
  minutes. **Clips** and **Comments** count rows that expand.
- *Clips tab.* "N clips", Copy clips, list of clip cards (thumbnail,
  duration, AI title). Tap plays the clip range.
- *Coaching tab.* Paid seat required. Holds AI scorecards when enabled.

## Search (`/app/search`)

Large query box. Results: "N Meetings", each with a highlighted transcript
snippet, speaker, and a timestamp that opens the meeting at that point.
**Include transcripts** toggle (default on; off = title only). Filters:
Recorder, Participants, Company, Trackers, Tags, Date, Playlists, Meeting
Type. Empty state shows Recent searches and Recent meetings with a ⋮ menu
per row.

## Updates (bell popover)

Notification feed, "All ▾" filter, Mark all as read, unread dots, relative
times. Observed types: new scorecard for a meeting; a person shared a meeting
with you.

## Playlists (`/app/playlists`)

Tabs: Playlists plus one per team. Filter by title. New playlist. Row =
thumbnail · name · "Created <date> by <user>" · owning workspace or team ·
meeting count. Detail page: title, created chip, team chip, filter, and a
day-grouped meeting list identical to Meetings. Header: Share · copy link · ✱
AI menu · + Add · ⋮.

## Stories and Clips (`/app/stories`, `/app/clips`)

*Stories* tab: "collections of Clips you can stitch together to summarize a
meeting, compile feedback, tell a narrative". New story. Empty in our
workspace.

*Clips* tab: every clip in the workspace. Row = thumbnail · AI title ("Conrad
questions SIEM alerts; prefers consolidating investigations in Google
SecOps") · date · duration · creator · source meeting · ⋮. Filter by title.

## Coaching (`/app/coaching`)

Paid seat required. Business feature: AI scorecards, trackers, team
interaction metrics.

## Ask anything (⇧A)

Floating panel "All Meetings · Beta". Scope chip, suggested prompts ("What
are my action items from today?", "What pain points were raised in my
customer calls recently?", "What decisions did my team make this week?"),
free-text box.

## Creation (+ New)

Desktop Capture (desktop app) · Bot recording (bot joins a meeting URL) ·
File upload (.mov .mp4 .mp3 .m4a) · Zoom import. Paid seat required.

## Settings

**Account** (`/app/settings/account`): My Meetings (auto-capture rules; paid
seat), App (redirects to desktop app), Profile (picture, email, preferred
name), Integrations (Google Calendar, Microsoft Calendar, Claude, ChatGPT,
MCP Clients, Zoom, Personal API with "Generate personal API token" and "View
API docs").

**Workspace** (`/app/settings/workspace`): General, Meetings, Templates,
Trackers are admin-only. Visible: Scorecards, Members, Billing, Plans,
Integrations (HubSpot, Salesforce, Slack, Aircall, Zapier, API).

**Plans** (as displayed): Free · Starter $15/seat/mo annual · Business
$29/seat/mo annual. Personal API is Starter+. Workspace API and advanced MCP
are Business+.
